## About the Project

Block Blast Hack v10.0.6 is an HTML game utility intended to run in a web browser through a static site. Its primary interface is an in-page mod menu, alongside support for removing ads and publishing the files through a lightweight GitHub Pages workflow.

The project targets the Block Blast web experience and does not require a separate backend server. The distribution approach combines browser-based access, SEO metadata, and a compact file layout suitable for static hosting.
